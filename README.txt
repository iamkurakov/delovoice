ДЕЛОВОЙС — публичный сайт delovoice.ru и автономная демоверсия кабинета.

Основные файлы:
- index.html — публичный лендинг (текст для индексации).
- demo.html — страница демоверсии.
- demo-v2.js — логика демо, вымышленные проекты, встречи, темы, задачи и отчёты.
- demo-v2.css — оформление демо в палитре рабочего кабинета, адаптивная верстка и тёмная тема.
- app.js — историческая версия демо; не подключается на demo.html и сохранена для сравнения.
- style.css — оформление публичного лендинга и прежней версии демо.
- cookies.js — согласие на аналитику; Яндекс.Метрика работает только после согласия.

Структура демо основана на пользовательском интерфейсе рабочего кабинета, зафиксированном в ветке prod приватного проекта 15 ноября 2026 года. Разделы основного меню: Главное, Встречи, Задачи, Темы, Требует проверки. Отдельно доступны проекты, подписка и оплата, справка, информация о сервисе и поддержка.

Демо позволяет:
- переключаться между двумя вымышленными проектами, создавать и переименовывать временные проекты;
- просматривать главную страницу с записью/загрузкой (показ готового примера), календарём, сроками, отчётами и темами;
- открывать встречу и переключаться между разбором, текстом и отчётом;
- получать подготовленные итоги встречи или периода и сохранять их через печать браузера в PDF;
- просматривать темы, связанные задачи и поручения, историю с цитатами и таймкодами;
- фильтровать задачи, менять демонстрационное состояние задач, отвечать на вопросы проверки;
- открывать учебные варианты экрана подписки, профиля, справки и поддержки.

Правила безопасности:
- Нет обращений к API рабочего кабинета, платных запросов LLM, записи/отправки аудио и создания платежей.
- Вымышленные данные хранятся в самом JavaScript. Введённые изменения сбрасываются при перезагрузке.
- Выбранный на компьютере файл не читается и не загружается: используется только его имя для индикации.
- Никакие письма или обращения из демо не отправляются.
- Внешний переход на https://app.delovoice.ru/ используется только для добровольного входа в настоящий кабинет.
- Тарифы и остаток часов в демо — учебные примеры, не сведения о подписке посетителя.

Для обслуживания: обновлять demo-v2.js/demo-v2.css при изменении реального интерфейса, повышать версии URL в demo.html для сброса кэша. Не копировать в публичный репозиторий клиентские данные, стенограммы или секреты. Публичный сайт и серверный кабинет развёртываются раздельно.

Состояние GitHub: рабочая ветка сайта — default branch репозитория iamkurakov/delovoice; фактическую автоматическую доставку с GitHub на сервер нужно подтверждать отдельно. Публикация кода в репозиторий не гарантирует, что сервер уже обновлён.
