ДЕЛОВОЙС — сайт продукта delovoice.ru и интерактивное демо.

Сайт отдаётся с сервера (Caddy), сервер забирает эту ветку из GitHub каждые 5 минут.

Файлы:
- index.html — главная. Весь текст лежит прямо в HTML, без скриптов: страницу читают поисковики и нейросети.
- demo.html + app.js — демо кабинета на вымышленной верфи «Северный ветер». Открывается сразу, без входа.
  Раздел «Итоги встреч» (demo.html#summary): итоги одной встречи и за период — последняя встреча, сегодня, месяц, год, свои даты. «Сохранить в PDF» открывает окно печати.
  Тексты — по документу «ДЕЛОВОЙС — весь сайт и демо простыми словами» (20.10.2026). Дословные слова участников встреч не меняются.
- privacy.html — сверху короткий пересказ простыми словами, ниже официальная политика без изменений.
- style.css — стили сайта и демо. robots.txt, sitemap.xml — для поисковиков.

Кнопки «Создать кабинет» и «Войти» ведут на настоящий сервис: https://app.delovoice.ru.
Старые ссылки вида delovoice.ru/#login и #overview переадресуются в демо.

Демо: «Добавить встречу» → «Показать разбор встречи» → «Нужно спросить» (выбрать день доставки шёлка) → «Сделать итоги встречи».
Данные вымышленные. Обработка записи и доставка сообщений имитируются, изменения сбрасываются после перезагрузки.
Шрифты Unbounded, Manrope, Jost и JetBrains Mono лежат в assets/fonts (лицензия SIL OFL) и отдаются с нашего сервера — без обращений к Google.
cookies.js — окошко согласия на cookie; Яндекс Метрика загружается только после «Согласен» (выбор хранится в localStorage, ключ dv_cookie).

Яндекс Метрика: счётчик 113913973 стоит на index.html, demo.html и privacy.html (в <head>, как выдала Метрика).
Цели: cabinet_click — нажали «Личный кабинет» (параметр place — какая кнопка: шапка, первый экран, тариф…),
demo_click — перешли в демо. Тот же счётчик стоит на app.delovoice.ru и в кабинетах — переходы видны в одном визите.
